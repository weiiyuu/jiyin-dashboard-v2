## 1. 頁面結構與共用操作

1. 頁面標題「機台運轉分析」；主切換為「區間分析／同期比較」。切換後切換適用的日期與粒度欄位，但保持以下三張**全寬獨立圖卡**、依序垂直排列。
2. 篩選 A1、A2、A3、A4、B1、B2、B3、B4；預設**全未選**，提供**全選、清除**；未選至少一台時三張圖顯示「請先選擇至少一台機台」，不觸發全機台統計查詢。
3. **區間／同期模式切換時清空機台選取**（使用者已確認，避免繼承上一模式的狀態）；模式內只變更日期或粒度時保留當前機台選取，但清除舊查詢結果並依新條件重新取得資料。
4. 三張圖共用頁面篩選；圖一點選高亮、圖二圖例線條顯示/隱藏、圖二的同期整體/單機檢視、圖三的各機台/整體檢視皆是**圖內局部狀態**，不修改全域機台篩選，也不意外影響其他圖。
5. 日期輸入使用 Asia/Taipei 業務日期。畫面起日／迄日皆**包含當日**；服務端以 `[起日 00:00, 迄日次日 00:00)` 表達查詢；單日是完整 24 小時，不是 0 天。來源時標 `24:00` 的絕對結束時間為次日 00:00，但歸屬來源日，不可重複計算或移日。
6. 要求至少完整一日；不得接受起日大於迄日或短於一完整日的自訂時段。
7. 在圖卡副標、Tooltip 與比較標籤中**顯示實際日期／日期範圍**，不可只有「期間 A／期間 B」。A/B 可以保留為圖例識別。

## 2. 模式與資料粒度

### 2.1 區間分析

- 選 **單日（完整 24 小時）**：趨勢分桶可切 **30 分鐘（48 個理論時點）／1 小時（24 個理論時點）**。
- 選 **超過一天**：趨勢每**日**一點，按真實業務日期排列。
- 粒度只影響圖二時間軸與分桶；同日期範圍的圖一 Green 累計及圖三燈號占比**不得因 30／60 分鐘切換而改變**。
- 理論時間點不代表有資料；Missing、Not Applicable、NULL 必須正確顯示，不能補假 0。

### 2.2 同期比較

| 同期類型 | 使用者選擇 | 圖二相對 X 軸 | 圖一統計指標 |
|---|---|---|---|
| 日對日 | A/B 各一個日期，完整 24 小時 | 相對 00:00～23:00、每小時 24 點 | 各期間 Green 累積小時 |
| 週對週 | A/B 各指定連續 7 天的**起始日期**，不強制週一 | 第 1～7 天，每天一點 | 各期間 Green 累積小時 |
| 月對月 | A/B 各指定**年／月** | 每月第 1～31 日；不存在的日為缺值、不可補零 | **該月 Green 累積小時 ÷ 當月日曆天數**，單位「小時／日」 |

- 期間 A 為基準；期間 B 為比較對象。圖二 A/B 對齊的是**相對位置**，不是跨月跨週接成單一連續的真實時間線。
- 月對月圖一是「平均每日加工時數」，但月對月**圖二每個點是該真實日期當日的 Green 小時**，不能使用月平均替代。
- **尚未結束的月份允許查詢**，但必須醒目標示「部分月份／資料不完整」及可用日數／覆蓋率；不能宣稱完整月比較，也不能改用「有資料天數」當成圖一平均分母。
- 日、週、月 A/B 比較都要顯示兩個期間的**真實起迄／年月**；Tooltip 在相對時點上對應到各自真實日期。

## 3. 數值真值、資料品質及時間規則

1. 每筆歷史燈號秒數是**區間秒數，不是累積計數器**。以 Active Batch 為準，避免多版本重複加總。
2. Green 加工小時＝有效 Green 秒數 SUM / 3,600。這是綠燈時間的**代理指標**，不等同已確認實際切削／成型工時，也不是稼動率。
3. **三態占比正式定案**：正式圖三僅顯示 Green（加工）、Yellow（待機／完成）、Red（異常燈號）；三色原始有效秒數先加總後再算：`G% = G/(G+Y+R)`、Y/R 同理。
4. None、Blue、White **不進圖三三態分母**，但必須完整保留在資料庫及原本的六態／品質來源。不要把 Blue/White 永遠判定為不可能出現；即使來源文件描述配置中不存在，歷史資料仍須保留異常證據。
5. 三態分母為零、無可靠有效觀測或任一必要數值缺失導致不可計算時，應顯示「無可計算的開機燈號時間」或具體品質狀態，**不輸出假 0%、假滿條**。
6. **三態統計資格不可直接等同舊的六態百分比**。先稽核 `jiyin-quality-v2` 的 Green／四態／六態資格與來源值；提出並實作**最小、可追溯、獨立的三態計算資格**或經證明等價的安全投影。必要時擴充後端查詢，**禁止在前端平均已有六態百分比或以 `100%-其他狀態` 暗算三態**。
7. 三態應以相同被核准的 eligible 區間中各色秒數加總為基準；不可把 NULL 當 0；嚴重來源品質問題必須按目前生效的 quality rule 排除對應統計，不得將 2025-06-04 00:54 已知嚴重秒數不足重新納入。
8. 完整區間 Green 合法值為 0 → 圖一可顯示 **0 小時**；資料缺失／不合格 → **NULL、斷線、無資料／品質不足**。若某一桶只收到部分機台數據，整體趨勢**不可標示成完整合計**；優先作斷點或明確的「部分資料」圖形及 Tooltips，並呈現每桶與整體 coverage。不可默默將缺漏當成下降。
9. 區分來源**到達率**與各指標**有效率**；品質警告是資料問題，不可當設備故障、企業 Alarm 或 Red 事件。
10. 任何資料契約變更必須保留原始值、指標資格、Import Batch/回復能力，不可重算時改寫來源 Excel、清除資料庫或跳過版本規則。

## 4. 圖一｜累積加工時數排行

**區間分析**
- 使用水平長條圖，X 軸 Green 小時、Y 軸選定機台編號；由高至低排序，最多八台完整顯示。
- 每條末端清楚顯示小時數，建議一位小數；Hover 顯示機台、時數、該台占**選定機台有效 Green 合計**的比例，並在資料不足時提示 coverage。
- 零加工有效觀測顯示真零；不合格／無資料不可生成假長條。

**同期比較**
- 每機台 A/B **兩根分組長條**，A/B 有明顯可辨色彩；預設依 B 的指標由高至低排序，月對月改按 B「小時／日」排序。
- Tooltip 顯示各期間真實日期／起迄、A/B 數值、`B−A` 及百分比變化 `(B−A)/A`；A=0 時百分比顯示不適用（差異小時仍保留）。
- 點擊機台高亮該台並淡化其他台；再次點擊取消，**只作用於圖一**。
- 月對月標題或副標明示「平均每日加工時數比較（小時／日）」；不得用「累積小時」誤稱。

## 5. 圖二｜機台運轉趨勢圖

**區間分析**
- 每台已選機台**獨立一條折線**；例如選 A1、A2、B4 → 3 條線，不可只畫一條選定機台加總。
- X 軸真實日期／時點；Y 軸**該時間桶內**的 Green 小時，不是一路加總的累積曲線；Y 軸從 0 起、適當刻度與「小時」單位。
- 單日 30 分鐘 48 理論點；1 小時 24 點；多日每日一點。可透過圖例隱藏／恢復單條折線，不能改動全頁篩選。
- Tooltip：機台、實際日期/時間區間、加工小時、coverage／品質，缺資料要斷線。

**同期比較**
- 固定顯示**期間 A／B 兩條對應折線**，提供「整體趨勢／單機趨勢」切換；整體是各時點**所有已選機台 Green 合計**，單機則由已選機台內再選一台。
- 切換局部檢視不改動上方選機清單。
- X 軸依日／週／月相對對齊；Tooltip 分別標示 A/B 的**真實日期**；月對月不補不存在的日期與 Missing 為 0。
- A/B 的圖例和顏色需與圖一期間色彩一致，在深紫主題下仍有足夠辨識度。
- 部分來源或部分機台缺漏時，依 §3.8 不得畫成完整合計。

## 6. 圖三｜燈號時間占比

**共通**
- 三態 **Green／Yellow／Red** 的水平 **100% 堆疊長條圖**，X 軸 0–100%。來源六態仍保留，不可修改原始資料。
- 圖例中文使用**「加工」「待機／完成」「異常燈號」**；「異常燈號」不等於已確認設備故障。
- Tooltip 保留**機台、期間實際日期、各色百分比、秒數及小時數、品質與分母說明**。
- 太窄的區段不強迫放入易重疊的小字，可於 Hover 或旁邊說明呈現。百分比圖例需清晰、文字和數值不要相隔過遠。
- 圖卡副標明示「僅以有效 Green、Yellow、Red 秒數為占比分母；None/Blue/White 不計入」；不得用 100% 三態代表全天 24h 的占比。

**區間分析**
- **預設「各機台占比」**：每台已選機台一條堆疊長條，依 Green 占比由高至低排序。
- **補充保留「整體占比」切換**：先對所有已選機台的合格 G/Y/R **秒數各自 SUM**，再除以三態總分母；不得平均各台百分比。
- 切換只作用於圖三，不改全域選機。

**同期比較**
- 提供「整體占比／各機台占比」切換。
- 整體模式期間 A、B 各一根；按各期間合格來源秒數分別計算，顯示具體日期與 A/B 對應，並顯示例如「加工占比 +12 **百分點**」，非 +12%。
- 各機台模式每台 A/B 兩根相鄰，最多 8×2=16 根；預設依 B 的 Green 占比排序，內容增加時採合理高度／內容區捲動但不壓小字。
- 不同期間獨立覆蓋率，不允許以較高覆蓋率一方掩蓋另一方。
